# Feature Specification: 设置界面布局优化与快捷键自定义

**Feature Branch**: `001-settings-hotkey-layout`
**Created**: 2026-01-10
**Status**: Draft
**Input**: User description: "我要完善设置功能，在设置界面增加一个设置快捷键呼出剪切板历史的功能，设置界面左右布局，左边是设置选项，右边对应每一个设置选项的操作"

**Clarifications Applied**:
- 设置界面范围：只包含"快捷键"一个设置选项（Q1:A）
- 访问方式：通过状态栏图标下拉菜单中的"设置"选项打开（Q2:A）
- 冲突检测：只检测明确的 macOS 系统保留键（约 20 个）（Q3:A）

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 快捷键自定义 (Priority: P1)

用户可以自定义用于呼出剪贴板历史的全局快捷键，不再局限于默认的 `⌃⌘V` 组合键。

**Why this priority**: 快捷键是用户与应用交互的主要入口，自定义快捷键是用户最常请求的功能。没有这个功能，用户可能因为快捷键冲突而无法使用应用。

**Independent Test**: 可以通过打开设置界面，修改快捷键，然后使用新快捷键呼出剪贴板历史来独立测试。完成后用户可以立即使用自定义快捷键访问应用。

**Acceptance Scenarios**:

1. **Given** 用户打开设置界面并选择快捷键设置选项，**When** 用户在快捷键输入框中按下新的组合键（如 `⌥⌘V`），**Then** 系统显示该组合键并保存设置
2. **Given** 用户已设置自定义快捷键，**When** 用户在任何应用中按下该快捷键，**Then** 剪贴板历史窗口正常呼出
3. **Given** 用户在快捷键输入框中，**When** 用户按下无效组合键（如单个字母键），**Then** 系统提示"请使用有效的组合键（至少包含一个修饰键）"
4. **Given** 用户在快捷键输入框中，**When** 用户按下 Escape 键或点击取消按钮，**Then** 快捷键设置保持不变

---

### User Story 2 - 通过状态栏访问设置 (Priority: P2)

用户可以通过点击状态栏图标，在下拉菜单中选择"设置"来打开设置界面。

**Why this priority**: 状态栏是 macOS 应用用户最常使用的访问入口，符合用户习惯。设置入口的可见性直接影响用户发现和使用设置功能。

**Independent Test**: 可以通过点击状态栏图标并选择"设置"来独立测试。完成后用户能够轻松找到并打开设置界面。

**Acceptance Scenarios**:

1. **Given** 应用正在运行，状态栏图标可见，**When** 用户点击状态栏图标，**Then** 显示下拉菜单包含"设置"选项
2. **Given** 状态栏下拉菜单已显示，**When** 用户点击"设置"选项，**Then** 设置界面打开并成为焦点窗口
3. **Given** 设置界面已打开，**When** 用户点击状态栏图标并再次选择"设置"，**Then** 现有设置界面获得焦点（不重复打开）

---

### User Story 3 - 设置界面左右布局 (Priority: P3)

设置界面采用左侧导航、右侧内容的布局方式，为未来设置项扩展预留空间。当前版本只包含"快捷键"一个设置选项。

**Why this priority**: 左右布局为未来设置项（如历史记录数量限制、主题选择）的添加打下基础。虽然当前只有一个设置项，但提前规划布局可以避免后续重构。

**Independent Test**: 可以通过打开设置界面，查看布局结构来独立测试。完成后界面呈现清晰的两栏布局。

**Acceptance Scenarios**:

1. **Given** 用户打开设置界面，**When** 界面加载完成，**Then** 左侧显示"快捷键"选项，右侧显示快捷键设置面板
2. **Given** 用户在设置界面，**When** 界面加载完成，**Then** 左侧"快捷键"选项处于高亮选中状态
3. **Given** 设置界面只包含一个选项，**When** 用户查看左侧列表，**Then** 列表不可滚动（内容完全可见）

---

### User Story 4 - 快捷键冲突检测 (Priority: P4)

系统检测用户设置的快捷键是否与 macOS 系统保留键冲突，并提供友好的提示。

**Why this priority**: 防止用户设置系统保留快捷键（如 ⌘Q 退出、⌘⌫ 删除）是重要的安全保障，但系统保留键数量有限（约 20 个），可以在核心功能实现后完善。

**Independent Test**: 可以通过尝试设置已知的系统保留快捷键来独立测试。完成后用户会收到清晰的冲突提示。

**Acceptance Scenarios**:

1. **Given** 用户尝试设置快捷键，**When** 该快捷键是 macOS 系统保留键（如 ⌘Q、⌘⌫、⌘W），**Then** 系统提示"此快捷键已被系统使用，请选择其他组合键"并阻止保存
2. **Given** 用户尝试设置快捷键，**When** 该快捷键不是系统保留键，**Then** 系统允许保存并成功注册

---

### Edge Cases

- 用户设置了包含功能键（F1-F12）的组合键，需要确保功能键正常工作
- 用户尝试设置只有修饰键（如只按 `⌃`）的组合键
- 用户在快捷键输入框中使用了输入法
- 用户在设置界面打开时，使用全局快捷键呼出剪贴板历史
- 用户设置的快捷键与 macOS 系统保留键冲突（如 ⌘Q、⌘⌫）
- 用户的键盘布局不是标准的 QWERTY 布局
- 用户在状态栏图标被隐藏时尝试访问设置
- 用户在设置界面未保存的情况下关闭窗口（应自动保存）
- 用户尝试设置与应用当前使用的快捷键相同的组合
- 设置界面打开时，用户再次点击状态栏"设置"选项

## Requirements *(mandatory)*

### Functional Requirements

#### 设置界面访问
- **FR-001**: 系统必须在状态栏提供图标，点击后显示下拉菜单
- **FR-002**: 状态栏下拉菜单必须包含"设置"选项
- **FR-003**: 点击"设置"选项必须打开设置界面并使其成为焦点窗口
- **FR-004**: 如果设置界面已打开，再次点击"设置"必须使现有窗口获得焦点（不重复打开）

#### 设置界面布局
- **FR-005**: 设置界面必须采用左右布局：左侧显示设置选项列表，右侧显示选中选项的详细设置
- **FR-006**: 当前版本的设置界面左侧只包含"快捷键"一个选项
- **FR-007**: 左侧的"快捷键"选项必须处于高亮选中状态
- **FR-008**: 右侧面板必须显示快捷键设置内容

#### 快捷键设置功能
- **FR-009**: 系统必须提供快捷键输入控件，支持用户通过按下组合键来设置快捷键
- **FR-010**: 系统必须验证用户输入的快捷键是否有效（至少包含一个修饰键：⌃、⌥、⇧、⌘）
- **FR-011**: 系统必须在输入控件中显示当前设置的快捷键
- **FR-012**: 系统必须保存用户设置的自定义快捷键，并在应用重启后保持有效
- **FR-013**: 系统必须立即应用新的快捷键设置，无需重启应用
- **FR-014**: 系统必须提供"恢复默认"按钮，将快捷键重置为默认的 `⌃⌘V`
- **FR-015**: 系统必须在用户尝试设置无效快捷键时显示友好的错误提示
- **FR-016**: 系统必须在设置界面关闭时自动保存所有更改

#### 快捷键冲突检测
- **FR-017**: 系统必须维护 macOS 系统保留快捷键列表（约 20 个常见的系统快捷键）
- **FR-018**: 系统必须检测用户设置的快捷键是否在系统保留快捷键列表中
- **FR-019**: 如果快捷键与系统保留键冲突，系统必须显示错误提示并阻止保存
- **FR-020**: 系统保留快捷键列表必须包括：⌘Q（退出）、⌘⌫（删除）、⌘W（关闭窗口）、⌘N（新建）、⌘O（打开）、⌘S（保存）、⌘Z（撤销）、⌘X/C/V（剪切/复制/粘贴）、⌘A（全选）、⌘F（查找）等常用组合

### Key Entities

- **用户设置**: 包含用户自定义的所有设置项，主要属性包括自定义快捷键组合
- **快捷键定义**: 表示一个全局快捷键，包含修饰键（⌃、⌥、⇧、⌘）和字符键的组合
- **设置选项**: 设置界面左侧导航中的每个选项，包含显示名称、图标、唯一标识符
- **系统保留快捷键列表**: macOS 系统保留的快捷键集合，用于冲突检测
- **状态栏菜单**: 应用在状态栏的下拉菜单，包含"设置"等选项

## Assumptions

- 用户使用标准的 macOS 键盘布局（QWERTY），但系统应支持其他布局
- 用户熟悉 macOS 常见的修饰键符号（⌃=Control、⌥=Option、⇧=Shift、⌘=Command）
- 用户期望设置界面遵循 macOS 原生应用的设计规范
- 用户只需要一个全局快捷键呼出剪贴板历史
- 状态栏图标在应用运行时始终可见
- 用户通过状态栏访问设置是主要方式，不提供其他访问入口
- macOS 系统保留快捷键列表是静态的（约 20 个常用组合），不需要动态更新

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 用户可以在 30 秒内完成快捷键修改（从点击状态栏图标到新快捷键生效）
- **SC-002**: 95% 的用户能够首次使用时就成功通过状态栏找到并打开设置界面
- **SC-003**: 设置界面的布局清晰度评分达到 4 分以上（5 分制）的用户满意度
- **SC-004**: 所有设置的快捷键在保存后立即生效，成功率 100%
- **SC-005**: 用户设置自定义快捷键后的使用频率保持不变（不会因为快捷键难以使用而降低）
- **SC-006**: 尝试设置系统保留快捷键时，100% 被正确拦截并提示用户
